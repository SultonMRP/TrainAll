Train All
by SDPhantom
3.3.5a port for SingleWoW (Vanilla / TBC / WotLK trainer UI)
https://www.wowinterface.com/forums/member.php?u=34145
https://www.curseforge.com/members/sdphantomgamer/projects
===============================================================================

Adds a "Train All" button next to Train in the class/profession trainer window.

UnZip contents into the "Interface\AddOns" folder in your WoW installation directory
