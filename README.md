# Train All

Shift-click **Train/all** in the class or profession trainer window to learn every available skill.

**3.3.5a port** of [SDPhantom](https://www.wowinterface.com/forums/member.php?u=34145)'s Train All. Vanilla / TBC / WotLK trainer UI (`ClassTrainerTrainButton`).

## Install

Download the release zip and extract it into `Interface\AddOns` so you have:

`Interface\AddOns\TrainAll\TrainAll.toc`

Then `/reload`.

## Use

Open a trainer. The Train button is labeled **Train/all**.

- Click: train the selected skill
- Shift-click: train every available skill

The tooltip shows how many skills are available and the total cost.
